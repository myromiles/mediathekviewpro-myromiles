# mediathekviewpro-myromiles
Official Stremio &amp; Streamflix Addon for German Public TV (ARD, ZDF, Arte, 3sat) with smart categories, presenter detection &amp; infinite scrolling. Developed by MyroMiles.
🔀 In Stremio installieren

Klicke einfach auf den Link oder kopiere die Adresse in dein Stremio-Addon-Suchfeld:

👉 In Stremio installieren


https://mediathekviewpro-myromiles-3.onrender.com/manifest.json

Anleitung:

    Kopiere die https://.../manifest.json URL.

    Öffne Stremio und gehe auf Addons (Puzzleteil-Symbol).

    Füge die URL oben in das Suchfeld ein und klicke auf Installieren.
